* Three detection hypotheses:

  * `H11` — Successful TGT request without Kerberos pre-authentication.
  * `H12` — No-pre-authentication TGT request using RC4-HMAC.
  * `H13` — Three qualifying requests from the same source within 60 seconds.

* Three custom Wazuh rules:

  * `100050` — Successful Event ID `4768` without pre-authentication.
  * `100051` — RC4-HMAC context for the no-pre-authentication request.
  * `100052` — Frequency correlation by source address.

### Detection Boundary

Wazuh observes:

```text
Event ID 4768
+
preAuthType = 0
+
successful result
+
RC4-HMAC context
+
request frequency
```

Wazuh does not directly observe password recovery or offline password testing.

### Security and Privacy

The public evidence excludes:

* complete AS-REP output strings;
* passwords and recovered passwords;
* reusable Kerberos material;
* complete SIDs;
* Wazuh backend document identifiers;
* `full_log`, `message` and `previous_output`;
* private dictionaries and credential-output files.
